# CraftTool

CraftTool is an MCPTool-inspired toolkit built specifically for Eaglercraft players, powered by Node.js.

## Features

- Server analysis
- Network utilities
- Server information tools
- Expandable tool system

## Requirements

- [Node.js](https://nodejs.org/) 24.0.0 or newer

## Installation

Clone the repository:

```bash
git clone https://github.com/melinaloveseldenring/CraftTool.git
```

Enter the directory:

```bash
cd CraftTool
```

## Usage

Start CraftTool directly using Node.js:

```bash
node index.js
```
